# Hydroturbine Blade Fault Diagnosis Research

## Overview

This project focuses on fault diagnosis of hydraulic turbine blade systems using vibration signal analysis.

## Research Background

Mechanical rotating systems may suffer from structural defects during operation. Early fault detection is important for improving safety and reliability.

## Methods

- Vibration signal acquisition
- Signal processing
- Frequency domain analysis
- Envelope analysis
- Fault feature extraction

## Tools

- MATLAB
- Signal Processing Toolbox
- ORIGIN
## Project Status

Research project in progress.
